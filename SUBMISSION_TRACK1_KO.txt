# OpenAI Game Challenge Track 1 제출 자료

## 필수 입력값

- 최종 게임명: `SYNDICATES & EMPIRES`
- 게임 소개: `경제·보급·전쟁이 하나의 세계에서 맞물리는 360일 실시간 전략 게임. 장수를 지휘하고 광산과 성을 점령해 생산망을 키우며, 살아 움직이는 AI 세력보다 먼저 경제 패권을 완성하세요.`
- 플레이 링크: <https://mymh121-spec.github.io/SyndicatesAndEmpires/>
- 로그인: 필요 없음
- 권장 환경: 데스크톱 Chrome 또는 Edge, 1280×720 이상
- 썸네일: `Submission/track1-thumbnail.png` (16:9 PNG, 10MB 이하)

게임 소개는 공백 포함 102자로, 제출 제한인 200자 이내다.

## 실행 및 조작

1. 플레이 링크를 열고 로딩이 끝날 때까지 기다린다.
2. `1인이서 하기`를 선택하고 새 세계 설정을 확인한 뒤 시작한다.
3. 좌클릭으로 지도 칸 또는 부대를 선택하고, 우클릭으로 이동·정찰·호위·습격·점령·채굴 등 상황별 행동을 연다.

- 지도 이동: `WASD` 또는 방향키, 마우스 가운데 버튼 드래그
- 확대/축소: 마우스 휠
- 플레이어 본거지로 이동: `L`
- 일시정지/재개: `Space`
- 시간 배속: 화면의 `1×`~`4×` 버튼
- 패널: 제목줄/접기 버튼으로 상태 정보와 상세 설명을 접거나 펼침

## 핵심 플레이 루프

1. 본거지와 성에서 장수를 중심으로 부대를 모집하고 편성한다.
2. 광산·성·시장으로 이어지는 생산 및 보급 거점을 확보한다.
3. 휘하 AI 장수에게 정찰·호위·습격·점령 임무를 위임한다.
4. 실제 지도 이동과 임무 결과가 보급, 생산, 시장 가격, 전투력에 연쇄 반영된다.
5. 360일 안에 경쟁 AI 세력보다 높은 경제·군사 우위를 만든다.

전투에서 승리하면 3% 확률로 AI 장수가 새로 합류하고, 패배하면 일반 장수가 5% 확률로 전사한다. 주인공 장수는 전사하지 않는다. 한 장수에게 병력을 과도하게 집중하면 병력 규모에 따라 연속함수 형태로 유지비 할증이 증가한다.

## 이번 챌린지 기간에 새로 완성한 작업

- 80×48 절차 생성 지도와 문명식 시작 전 세계 설정
- 경제 미션을 실제 지도 좌표와 연결하고 임무 결과를 생산·보급·시장에 반영
- 위임 부대의 실제 이동 및 정찰·호위·습격·점령 수행
- 가까운 광산 탐색을 넘어 경제·군사·장기 전략을 함께 평가하는 세력 AI
- 간소화된 항구 기반 해상 이동과 향후 확장을 위한 HIVE 연동 슬롯
- 장수 생성·전사 규칙, 주인공 불사, 병력 집중 유지비 곡선
- 선택 유지, 접이식 정보 패널, 바깥 정보 밀도 축소 등 플레이 UI 정리
- Windows 설치 파일과 브라우저 즉시 실행 WebGL 배포 경로

## Codex와의 협업

이 게임의 A to Z 제작 작업은 Codex와 함께 진행했다. Codex가 기획을 코드로 옮기는 구현자이자 검증자·빌드 담당자·배포 담당자로서 전체 제작 흐름을 수행했고, 제작자는 플레이하면서 느낀 부족한 점과 필요한 시스템을 계속 찾아내어 요구사항으로 제시했다. 서로 다른 장르에서 유용한 요소를 그대로 복사하지 않고, 경제·미션·군사·AI·UI를 하나의 게임 루프로 융합하는 방향은 제작자가 생각하고 선택했다.

작업 방식은 `부족한 점 발견 → 필요한 시스템을 함께 정의 → Codex의 구현·테스트 → 실제 플레이 피드백 → 다음 시스템으로 확장`의 반복이었다. 따라서 결과물은 Codex가 일방적으로 생성한 게임이 아니라, 제작자의 문제의식과 시스템 설계를 Codex가 A to Z로 구체화한 협업 결과다.

### 어디에 Codex를 사용했는가

도메인 규칙 정리, Unity C# 구현, 데이터·게임플레이 연결, UI 구조 정리, 테스트 보강, WebGL 빌드 자동화, 브라우저 실행 검증, Git 배포 및 제출 문서 정리까지 제작 전 과정을 Codex가 담당했다. 특히 요청이 모호한 경우에도 기존 코드와 플레이 흐름을 분석해 필요한 파일과 시스템 경계를 찾아 구현했다.

### 무엇을 구현했는가

경제와 지도 임무의 연동, 자율 이동하는 휘하 AI, 세력 전략 평가, 광산·성 점령과 보급, 장수 생존 규칙, 연속 유지비 할증, 간소화된 해상 이동, 접이식 정보 UI, HIVE 확장 경계, 배포 빌드를 함께 구현했다.

### 어떤 문제를 해결했는가

서로 분리되어 있던 경제 시뮬레이션과 지도 전쟁을 하나의 일일 정산 흐름으로 연결했다. 또한 판정용 PC에서 별도 설치 없이 실행할 수 있도록 Unity WebGL 빌드와 정적 호스팅 구성을 추가하고, 화면에서 불필요하게 반복되던 수치와 설명을 상세 보기 안으로 이동했다.

### 제작자가 생각하고 융합한 부분은 무엇인가

제작자는 기존 SLG에서 부족하다고 느낀 경제와 전쟁의 연결, 미션의 실제 지도 수행, 휘하 AI 장수의 자율성, 점령 이후 난이도 변화, 말 자원과 기병 유지비, 장수 생존 규칙, 정보 과밀 UI 문제를 찾아냈다. 또한 필요한 요소와 추후로 미룰 요소를 직접 분리하고 서로 융합할 시스템을 선택했다. 안개 시스템 제외, 해상전 단순화, 편성 비율 버튼 제거, 승전·패전 장수 확률, 주인공 불사, 병력 집중 유지비 곡선, 정보 패널 축소, HIVE는 작동 구현 대신 확장 공간만 유지하는 범위가 그 결정에 해당한다. Codex는 이 판단을 실제 게임 규칙, 코드, 테스트, WebGL 배포본으로 구체화했다.

## HIVE 및 출시 확장성

현재 심사용 싱글플레이 코어에는 HIVE 의존성이 없다. 대신 인증, 업적, 클라우드 저장, 분석, 알림, 개인 매치메이킹을 어댑터 경계 뒤에 연결할 수 있는 비활성 확장 슬롯을 유지한다. 실제 서비스 연결에는 HIVE SDK 설치와 App Center 설정이 추가로 필요하다.
