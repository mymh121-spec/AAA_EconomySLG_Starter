PvP 출시 전 필수
1. HIVE matchingId를 내부 경기/방으로 교환하는 연결 API
2. 여러 경기를 동시에 보관하는 MatchRegistry
3. 계정 로그인과 짧은 수명의 세션 토큰
4. HTTPS 도메인, Caddy/Nginx 리버스 프록시
5. systemd 서비스, 로그 로테이션, 모니터링
6. 경기 데이터 보관·백업·삭제 정책
7. 패킷 유실, 중복, 지연, 악성 입력, 재접속 부하 테스트

주의
- 현재 서버는 한 프로세스에 설정된 단일 경기만 운영한다.
- 공인 IP의 5100 포트를 직접 열지 않는다.
- Unity 씬이나 저장소에 Bearer 토큰을 저장하지 않는다.
- 온라인 경기의 최종 상태는 항상 서버 응답을 사용한다.
- 자세한 서버 상태는 SERVER_PVP_V0_2_HANDOFF_KO.md와 Server/README_KO.md를 본다.
